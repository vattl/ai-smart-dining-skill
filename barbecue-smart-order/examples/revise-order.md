# 用例：多轮调整

初始条件：预测试门店 `shop_id=3`，6 人、150 元、2 人不吃辣。

1. 用户说“其中 1 人不吃牛肉”：只为该成员增加硬限制，保留人数、预算和其他不辣约束；调用 `adjust_meal_plan`。
2. 用户说“再便宜 20 元”：将预算改为 `13000` 分并重新求解；总价不得超过新预算。
3. 用户说“按这个下单”：先展示最新候选，不把这句话当作最终订单确认。
4. 创建草稿并调用 `validate_order_draft`。如果价格或库存变化，说明旧确认失效并重新展示。
5. 用户明确说“确认下单，按以上明细提交”后，才调用 `submit_order`，并携带唯一幂等键。
