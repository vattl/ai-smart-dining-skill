# Migration from v3.4

v3.5 does not replace capability-aware repair; it extends it across UI/API/frontend/backend boundaries.

For existing task templates, add:

- Layer Impact Matrix
- Contract Delta when interface/semantic contracts change
- Semantic UI Impact when business meaning changes
- End-to-End Data Flow evidence for cross-layer tasks

For existing `/change`, `/feature`, `/repair`, `/verify`, `/continue`, apply the new cross-layer rules by default.
