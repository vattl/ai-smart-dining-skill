# UI Design Methodology

v3.6 requires meaningful UI work to reason before drawing.

The operational sequence is:

Product Context → User Goal → Information Hierarchy → Information Architecture → Visual/Action Hierarchy → Density/Spacing/Typography → Component Strategy → Implementation Feasibility → Prototype → Critique → Approval → Lock → Translation → Verification.

The methodology prioritizes user-task clarity, semantic grouping, coherent density, restrained visual weight, progressive disclosure, state completeness, project fit, and implementation feasibility.
