# Design artifacts

For UI work, keep implementation-aware prototype artifacts, approved golden references, UI contracts, component mappings, fixtures and visual verification evidence here.

Cross-layer UI changes should also reference their Layer Impact Matrix and Contract Delta where applicable.

## v3.6 implementation-aware design

For structural UI work, design artifacts may include UI design strategy, legacy decomposition, component capability audit, prototype technical plan, design critique, and UI lock contracts. The approved prototype is a design target; production code must be translated into the real stack without silently redesigning it.
