# /ui-critique

Review a UI/design as an independent product-design critic rather than its author.

Evaluate:
- product-context fit
- primary-task clarity
- information hierarchy
- grouping/alignment
- visual weight
- spacing system
- typography hierarchy
- density consistency
- action hierarchy
- progressive disclosure
- state coverage
- content stress resilience
- responsive strategy
- accessibility
- implementation feasibility
- legacy resemblance when intent is REFACTOR/REDESIGN

Return:
- PASS
- REVISE
- REFACTOR_INSUFFICIENT
- IMPLEMENTATION_RISK

List material issues by severity and propose specific corrections, not vague aesthetic comments.
