# Design Baseline Rules

`DESIGN_SYSTEM_PROFILE` records the accepted production design language.

Record as applicable:
- product type and design goals
- visual direction
- density
- typography/font stack
- spacing/radius scales
- semantic color roles
- control/table/dialog sizing conventions
- surface hierarchy
- icon system
- state patterns
- responsive rules
- accessibility expectations

## UI intent behavior
- REFINE: follow current design baseline closely
- REFACTOR: preserve product capability and general design language unless user asks for visual-system change
- REDESIGN: may propose a new design direction; it becomes baseline only after accepted product-wide adoption

Temporary local deviations are not automatically promoted to design-system rules.
