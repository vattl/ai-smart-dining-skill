# Work Item Rules

A Work Item is the primary lifecycle identity for meaningful engineering work.

## Required identity

Use `WI-NNN` or the project's equivalent stable ID.

Subordinate artifacts must reference the parent Work Item.

## Suggested states

REQUESTED
UNDERSTANDING
DISCOVERING
DESIGNING
PLANNED
IMPLEMENTING
SELF_VERIFYING
IN_REVIEW
ACCEPTANCE
READY_TO_INTEGRATE
INTEGRATED
RELEASE_READY
RELEASED
MONITORING
DONE
BLOCKED
INTERRUPTED
PARTIAL

## Truth

State describes evidence-backed reality, not intent.

Do not mark DONE when frontend/consumer work is known to remain required.
